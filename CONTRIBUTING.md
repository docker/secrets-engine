# Contributing

Thanks for your interest in contributing to Secrets Engine.

## Sign your commits (DCO)

Every commit must carry a [Developer Certificate of Origin](https://developercertificate.org/)
sign-off. It certifies that you wrote the change, or otherwise have the right
to submit it under the project's [Apache 2.0 license](LICENSE).

Add the sign-off with `-s`:

```sh
git commit -s -m "your commit message"
```

This appends a trailer built from your `user.name` and `user.email`:

```
Signed-off-by: Your Name <you@example.com>
```

To sign off commits you already made, run
`git rebase --signoff origin/main` and force-push your branch.
